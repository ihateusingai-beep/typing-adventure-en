# STYLE BIBLE · 電腦打字大冒險（角色向）

**Lock for all P0 gens · Ken Ghibli preference**

## Visual
- Studio Ghibli soft pastel watercolor, hand-painted feel, warm golden-hour light
- Soft edges, gentle grain, cozy atmosphere — **not** chibi, **not** hard anime cel
- Young hero ~18–20, East Asian, friendly, readable silhouette
- Clean subject, **no text, no letters, no logos, no watermark, no UI**

## Palette
- Paper cream `#f2eddf`, ink green `#152b29`, jade `#355d4d`, soft gold `#c8b77f`
- Sky/mist pastels; avoid neon cyberpunk

## Character consistency
- Same face language: large soft eyes, small nose, gentle mouth
- Proportions: slightly tall anime-realism (Ghibli youth), head ~1/6–1/7 body on full shots
- Feet planted for sprites; transparent or pure white bg for cutouts (we key white→alpha)

## Negative (always append)
`no text, no letters, no logos, no watermark, no UI chrome, no photoreal skin pores, no horror, no gore`

## Output pipeline
1. MiniMax `image-01` English prompts
2. Post: resize → webp; portraits key white bg; build motion/enemy sheets from stills if needed
