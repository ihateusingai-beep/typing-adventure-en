# 文本重寫構思 · SEN 中度 · 廣東話口語

**狀態：只構思，未改 code**  
**對象：** 將軍澳培智／中度智障（低識字、短句、要聽得明）  
**產品：** 電腦打字大冒險（英文鍵練習）

---

## 0. 一句結論

而家文案偏 **書面武俠**（少俠、符印、鍵心碑、委託）。  
學生難明 → 要改成 **短句 + 粵語口語 + 具體動作**（「撳 F」「兩隻手」）。  
**武俠皮可留少少**（師傅／衣服），但 **指令必須口語化**。

## 1. 改文原則（鎖死）

| # | 原則 | 例 |
|---|---|---|
| 1 | **一句一事** | ✗ 長句兩件事 → ✓ 一句一個動作 |
| 2 | **粵口語** | 「撳」「睇清楚」「得㗎喇」「唔使急」 |
| 3 | **字少** | 對話每句 **≤12 字** 優先；按鈕 **2–6 字** |
| 4 | **具體** | ✗ 符印／基準列 → ✓ 凸點、F 鍵、左手 |
| 5 | **正面** | 錯：唔罵；「唔緊要，再試」 |
| 6 | **少抽象** | ✗ 江湖、名動、劍心 → ✓ 學打字、過關、換衫 |
| 7 | **稱呼** | 「少俠」→ **「同學」** 或用名；師傅可留「老師」或「師傅」二揀一（推：**老師**） |
| 8 | **鍵盤詞** | 統一：**左手／右手／食指／F／J／凸點／撳** |
| 9 | **唔用** | 文言文、成語堆、雙關、長比喻 |
| 10 | **可讀可講** | 老師可讀出；學生跟做 |

- **新：一齊學打字啦。由 F 開始。**

### 主頁
- 舊：江湖，等你出招。  
- **新：準備好未？繼續練習。**

### 章 C01 intro
- 舊：鍵心碑的符印散落了。青衡師傅說，先從雙手的家找起。  
- **新：今日練兩隻手。先搵 F 同 J。**

### S01-01 對話
- 舊：先別急著出劍，把手放到鍵盤上。／摸摸 F 上的小凸點…  
- **新：**
  1. 手放鍵盤。  
  2. 左手食指摸 F 凸點。  
  3. 見到 F，就撳一下。

### 戰鬥提示
- 舊：先看準，再出招。  
- **新：睇清楚，再撳。**

- **新：啱喇！下一個。**
- 舊：✕ 按錯了 · 再按 F 試一次。  
- **新：唔啱。再撳 F。**

## 4. 結構建議（對話）

每關 opening **最多 3 句**（而家都係 3，保持）：  
1. 做咩  
2. 邊隻手／邊粒鍵  
3. 點做（撳）

Closing **1–2 句**：讚 + 下一步（可選）。

章名可二擇：
- **A 保留詩意短名**（劍心初醒）+ 下面口語說明  
- **B 全口語**（第 1 章：F 同 J）← **中度更推 B**

推介：**章名 B 口語；關卡名口語**（例：搵左手 F）。
